如何使用編輯功能
開啟編輯模式後，可修改每項行程的時間、地點、說明、Google Maps 連結及預約狀態，也能新增或刪除行程。按「儲存這項」會先儲存在目前瀏覽器。
重要：靜態網站不會自動把你這邊的修改同步給老婆。要讓她看到最新版本，請按「下載更新版網站（HTML）」，將下載的檔案重新命名為 index.html，再上傳到 GitHub Repository 覆蓋原檔案。完成後公開網址就會更新。也可以用 JSON 備份／匯入在不同裝置間轉移修改。
